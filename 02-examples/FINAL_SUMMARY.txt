🚀 CÓMO EMPEZAR
================================================================================

1. VERIFICAR SETUP:
   Windows (PowerShell): .\verify-setup.ps1
   Linux/macOS (Bash): bash verify-setup.sh

2. INSTALAR POSTGRESQL (si no lo tienes):
   Windows: https://www.postgresql.org/download/windows/
   Linux/WSL: sudo apt-get install postgresql

3. CREAR BASE DE DATOS:
   psql -U postgres
   CREATE DATABASE orderdb;
   \q

4. INSTALAR DEPENDENCIAS:
   npm install --legacy-peer-deps

5. INICIAR SERVIDOR:
   npm run start:dev

6. ABRIR GRAPHQL:
   http://localhost:3000/graphql

7. CREAR PRIMER PEDIDO:
   mutation {
     createOrder(input: {
       customerId: "cust-123"
       items: [{productId: "PROD-001", quantity: 2, unitPrice: 50}]
     }) {
       id status totalAmount
     }
   }

📞 TROUBLESHOOTING RÁPIDO
================================================================================

ERROR: "Connection refused" PostgreSQL
  → Verifica: DB_HOST, DB_PORT, DB_USER en .env
  → Asegúrate que PostgreSQL está corriendo

ERROR: "FATAL: password authentication failed"
  → Contraseña incorrecta en .env
  → Por defecto es: postgres

ERROR: "Cannot find module '@nestjs/apollo'"
  → Reinstala: npm install --legacy-peer-deps
  → Luego: npm run build

ERROR: "EADDRINUSE :::3000"
  → Puerto 3000 está en uso
  → Usa otro puerto: PORT=3001 npm run start:dev

Para más ayuda: Ver TROUBLESHOOTING.md
